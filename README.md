# Alexis Obi — Personal Website

A lifestyle, beauty, and tech portfolio website built with vanilla HTML, CSS, and JavaScript.

## Pages

- **Home** (`index.html`) — Hero, featured blog posts, about teaser, gallery preview
- **Blog** (`blog.html`) — Featured article, filterable post grid
- **Gallery** (`gallery.html`) — Immersive photo gallery with lightbox
- **Portfolio** (`portfolio.html`) — Professional services and consultation
- **Shop** (`shop.html`) — ISO Hair premium extensions e-commerce

## Tech Stack

- HTML5 semantic markup
- Vanilla CSS with custom properties (design tokens)
- Vanilla JavaScript (no frameworks)
- Google Fonts (Cormorant Garamond, Inter, Brittany Signature)
- Font Awesome icons (via CDN)

## Fonts

| Font | Usage |
|---|---|
| Cormorant Garamond | Headings |
| Inter | Body text, UI elements |
| Brittany Signature | Decorative script accents |

## Development

Simply open `index.html` in a browser, or serve locally:

```bash
# Using Python
python3 -m http.server 8000

# Using Node
npx serve .
```

## Deployment

The site is a static HTML project — deploy to any static hosting provider (Vercel, Netlify, GitHub Pages, etc.).
